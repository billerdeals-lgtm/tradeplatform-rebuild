# FT Compass · 外贸客户开发工作台

自研外贸一体化工具（重建自 tradeplatform 设计，代码独立编写）。

纯静态单页应用：**无需后端、无需数据库**，业务数据全部存在访问者自己的浏览器 localStorage。

## 功能

- **线索 Pipeline**：客户线索 CRUD、阶段漏斗、CSV 导出
- **AI 能力（Agnes 2.5 Flash）**：线索评分 / 开发信生成 / 客户回复草稿 / 异议应对 / 今日优先级排序 / 本期复盘 / 节假日问候 / 单证单单一致校验 / 备注英文润色
- **待办任务**：关联线索、到期提醒、AI 排序
- **话术库**：76 封中英双语模板，模板打底 + AI 个性化改写双引擎
- **单证中心**：20 张出口单证（PI/CI/PL 等），共享字段一次填写全单联动，A4 打印
- **复盘增长**：漏斗统计 + AI 三发现三动作一砍掉
- **复购 · 节假日**：节日提醒 + AI 问候生成
- **数据备份**：一键导出 / 恢复 JSON

## 使用

1. 打开首页，右上 **⚙ AI 设置** 填入你的 OpenAI 兼容网关（Base URL `/v1` 结尾）、API Key、模型名（不填 AI 也能用除 AI 外的全部功能）
2. 配置存浏览器 localStorage，仅本机可见

## 部署

GitHub Actions 自动部署到 GitHub Pages（`.github/workflows/deploy-pages.yml`），推送到 `main` 即发布。

> 注意：纯静态托管下 CORS 部分网关可能限制浏览器直连，若 AI 请求被拦，换支持 CORS 的网关或自建 Cloudflare Worker 反代。

## 安全

- 代码不含任何密钥；请勿提交真实 key 到本仓库
