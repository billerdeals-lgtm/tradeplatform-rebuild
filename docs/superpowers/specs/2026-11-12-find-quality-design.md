# 找客户命中率与数据干净度优化设计

日期：2026-11-12
状态：已确认，已实现
范围：`modules/find.html`、`js/sources.js`、`tools/test-find-quality.mjs`

## 目标

- 不再误杀经销商/进口商（命中率）。
- 结果里的公司名、国家、邮箱、重复项更可信（干净度）。
- 不新增后端、不新增代理域名、不改变「数据只存本机」。

## 规则引擎

- 强信号（自称 manufacturer/factory、FOB/EXW、供应商平台）仍然直接剔除。
- 弱信号（add to cart、in stock、$/unit、product catalog）只在**没有买家信号**时剔除。
- 买家信号：distributor / importer / wholesaler / dealer / reseller / trader / retailer / we import / procurement / sourcing 等。
- 采购询盘只认 RFQ、request for quote、looking for supplier、tender、MOQ 等强写法；
  「我们自己的报价单 / 购物车」不算询盘，避免经销商被 +2 分虚高。
- 名字里直接带 manufacturer / supplier / exporter / OEM 的，视为同行剔除（除非页面同时有买家信号）。

## 合并去重

- 键从「完整 host」改为「可注册域名」：`shop.acme.com`、`acme.com` 合并。
- 同名跨域合并必须同时满足：同国（或一方未知）+ 域名核心词一致（或一方没有官网）。
  `acme.com` 能并上 `acme.co.ke`，不会把 `acmesolar.com` 和 `acme.co.ke` 并掉。
- 合并时字段取更可信的一份，`_sources` 累加，用于「多源」徽标与排序。
- 「换一批」同时按名称和可注册域名排重。

## 公司名

- 域名拼出的名字先取可注册域名的核心词，避免 `shop.xxx.co.ke → "Shop"`。
- 抓到官网后用首页标题升级，但标题必须与域名核心词对得上；
  文章标题、导航标题、「Company in Kenya」这类描述句不采用。
- 只有 DDG/Bing/目录/AI 搜索路径产生的域名名才允许升级（`_nameFromDomain`）。

## 联系方式

- 邮箱按岗位排序：采购/买手 > 销售/出口 > info/contact > 其他；
  webmaster / 建站 / 营销等角色降权。
- 企业邮箱域名与官网一致加分；免费邮箱保留；域名对不上的企业邮箱降权。
- 同一邮箱域出现在 ≥3 家不同公司上，判为建站商/模板/代收，清空该批邮箱。
- `tel:` 链接优先作为电话号码来源。

## 国家与市场

- 证据分级：官网 ccTLD > JSON-LD `addressCountry` > `Country:` / `based in` > 页脚地址 > 国际电话区号。
- 电话必须是完整号码（8–15 位，允许空格/括号/短横线），产品参数 `+40°C` 不再被当成罗马尼亚。
- 页脚地址支持缩写（Rd / Ave / Blvd）和 Markdown 链接，`[地址](地图链接)` 可取到国家。
- 多国公司：页脚是海外分公司地址、而页面有 ≥2 个同区号电话时，以电话所在国为准
  （例：Power & Sun 页脚印度、电话阿联酋 → UAE）。
- 电话区号需要多次出现或唯一候选才采用；`+1` 不猜美国/加拿大。
- 每条结果记录 `_countrySrc`，界面 tooltip 显示依据。
- 目录详情页（Europages 等）正文不作国家证据。
- 选了目标市场时，域名/结构化/明确写法/来源目录给出的国家不属于该市场 → 剔除并记日志；
  页脚、电话区号、未知国家保留，避免误杀。

## 召回

- DDG 关键词从 4 条提到 5 条。
- AI 意向评分从 15 家提到 24 家，`maxTokens` 随条数增长。
- 高分缺邮箱的前 6 家：先抓官网自己的联系页，再回退到搜索补全。
- jina 新增 16 次/分钟滑动窗口限流，避免一轮抓取把免费额度打满后全部 401。

## 界面

- 意向列新增 `✓ 核验`、`多源 N` 徽标；国家列 tooltip 显示依据。
- 筛选条新增「只看有联系方式」「只看已核验」。
- 意向分相同时按证据强度排序：多源印证 > 已核验 > 有联系方式。
- 失败归因新增「多数来源抓取失败（部分连通但没有返回公司）」。
