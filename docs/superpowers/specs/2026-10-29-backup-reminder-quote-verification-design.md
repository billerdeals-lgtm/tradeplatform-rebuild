# 备份提醒 + AI 核价提示 设计

日期：2026-10-29
状态：已实现

## 背景

两个不显眼但会出事的口子：

1. 数据全在 `localStorage`，唯一的真实死法是“忘了备份”。备份按钮藏在侧栏底部，没有时间记录，也没有任何提醒。
2. AI 生成的报价明细直接落进 `#itemsBody`，单价看起来和人工报价完全一样。发出去之前没有任何标记提醒核价，导出也没有留痕。

## 一、备份逾期提醒

### 规则

- 记录键：`localStorage.ftc_last_backup`（ISO 时间字符串）。
- 判定数据：`leads` / `todos` / `quotes` / `docs` / `products` / `comps` 任一非空。`cfg`、`searches`、`profile` 不算业务内容，避免“只改过一次设置”就催备份。
- 提示条件：有数据，且（从未备份 或 距上次备份 > 7 天）。
- `ftc_last_backup` 不写入备份 JSON；每台设备各自记录自己的备份时间。

### 交互

- 位置：`.content` 内、`#home` 与 `iframe` 上方，全宽提示条；首页和所有模块共用同一个壳，所以切页不消失。
- 文案：
  - 从未备份：「该备份了：还没有备份过」
  - 已备份：「该备份了：上次备份是 N 天前」
- 操作：
  - 「立即备份」→ 现有 `backupAll()`；下载触发后写入 `ftc_last_backup` 并立即隐藏。
  - 「稍后」→ `sessionStorage.ftc_backup_snooze = '1'`，仅当前标签页本次会话隐藏，新开标签页仍会提醒。
- 备份成功、`go('home')` 刷新时都会重新计算，已备份则自动消失。

### 布局

- 桌面：提示条 `flex:0 0 auto`，iframe 继续 `flex:1`。
- ≤860px：`.content.has-banner iframe` 与 `#home` 改为 `height:auto; min-height:0`，由 flex 分配剩余高度，避免 `100dvh` 与提示条叠加后溢出。

### 无障碍

- 容器 `role="region" aria-label="备份提醒"`，文案节点 `role="status"`（出现时播报一次）。
- 不自动聚焦、不遮挡内容；两个按钮是原生 `<button>`。
- 文字 `--warn-text` 在 `#fff7e6` 上 4.99:1；按钮边框 `#9a6b16` 在浅底上 4.39:1，满足 1.4.11。

## 二、AI 估算单价核价提示

### 交互

- 明细表标题行下方、表格上方显示：`⚠️ 单价为 AI 估算，发送前请人工核价`，右侧「已核对」。
- 只在 `aiGenQuote()` 成功返回明细后出现；手工录入、从商品库选择不出现。
- 保存后随报价持久化，重新打开仍在；点「已核对」才隐藏并立即回写当前报价。

### 数据

报价记录新增三个字段：

| 字段 | 含义 |
| --- | --- |
| `aiEstimated` | 当前明细是否仍为 AI 估算、未人工核对 |
| `aiGeneratedAt` | AI 生成时间（ISO） |
| `aiVerifiedAt` | 人工点「已核对」的时间（ISO） |

老报价没有这些字段：一律按 `aiEstimated = false` 处理，不回溯修改。

### 隔离与留痕

- 提示条只在编辑器内。打印样式仍只显示 `.paper`，客户版 Excel 也不读取这些字段。
- 「Excel 数据版」报价头新增 `AI Assisted`、`Price Verified`、`AI Generated At`、`Price Verified At` 四行，供内部追溯。
- 客户可见的打印 / 客户版导出不出现任何 AI 字样。

## 验证

- 静态校验：备份条位置/语义/阈值/写入时机、核价提示位置/文案/持久化/回写、Excel 字段、版本号，全部通过。
- 回归：`verify-a11y.mjs`（24 dialog / 30 scope / 19 alt）、`verify-round2.mjs`、`node --check` 全部通过。
- 既有测试：license 31/31、docs-i18n 2951/2951、ai-verify 15/15、ai-source 11/11。
- 对比度：新增文字 4.99:1，按钮边框 4.39:1，按钮文字 4.69–5.93:1。

## 已知边界

- “备份成功”以浏览器触发下载为准，无法确认文件是否真的落到磁盘。
- 提示条位于首页壳内，独立打开某个 `modules/*.html` 时不会出现；模块内仍可通过侧栏备份。
- AI 留痕只覆盖报价单，其他 AI 产出（开发信、客户评分）暂未纳入导出。
