# FT Compass · 移动端 / AI 挖掘可信度 / 竞品库 设计

日期：2026-10-21
范围：三个独立但同批交付的改进项
状态：已确认，进入实现

## 背景

外贸经理反馈三点：

1. 移动端不可用：外壳是固定侧边栏 + iframe 的桌面结构，模块内部是固定宽度双栏。
2. 「AI 挖掘」会产出不存在的公司：提示词让模型“从训练数据列出真实公司”，且结果零核验。
3. 数据模型有 `comps`（竞品）集合，但没有对应界面。

## 目标

- 手机（≥360px）和小平板（≤860px）能完成核心工作流：找客户 → 线索 → 客户 360 → 报价 → 单证。
- AI 来源不再直接产出未经核验的公司；模型只做“搜索规划”，公司必须经过真实网络核验。
- 竞品数据可录入、编辑、删除，并能按客户查看。

## 非目标

- 不做原生 App / PWA 离线安装。
- 不改变现有数据结构、不加后端。
- 不重做视觉设计，只做布局适配。
- 不引入第三方 UI 框架。

## 一、移动端响应式

### 外壳（index.html）

- 断点：`max-width: 860px`。
- 新增移动顶栏：汉堡按钮、当前模块名、授权状态小圆点。
- 侧边栏变为抽屉：`position:fixed`，默认 `translateX(-100%)`，打开时滑入，带遮罩；点击导航项或遮罩自动关闭。
- 内容区占满宽度，iframe 高度 = 视口 − 顶栏。
- 首页统计卡改 2 列，快捷按钮换行。

### 模块（14 个 HTML）

- 新增 `assets/responsive.css`，所有模块在 `tokens.css` 之后引入。
- 规则：
  - `main` 由 flex 改为 block，左右栏上下堆叠。
  - `.left` 取消固定宽度。
  - 表单网格、双列卡片改单列。
  - 数据表格横向滚动；纸面内的表格保持正常布局。
  - 按钮组、工具条换行。
  - 弹窗宽度 96%。
- 单证 / 报价纸面：手机端横向滚动，不缩放，保证与打印版式一致；打印样式显式 `min-width:0`。

### 验收

- 390×844 与 768×1024 下，以下页面无横向溢出、无内容被裁切、主要按钮可点：
  找客户、线索、客户 360、待办、报价、单证、商品库、利润计算器。
- 桌面端（≥1024px）视觉不变。

## 二、AI 挖掘可信度

### 提示词（agnes-ai.js）

- `findBuyers` 改为“搜索规划器”：
  - 输出 `queries`：8–12 条本地化搜索词（含 importer / distributor / wholesaler / RFQ 等意图词）。
  - 输出 `companies`：仅限模型高度确信、且能给出官方域名的公司；不确定则省略，禁止编造。
  - 不输出推测的邮箱/电话；字段未知留空。
  - `temperature: 0.2`。

### 代码（sources.js）

- AI 搜索词走真实 DuckDuckGo 搜索，结果按域名生成候选（与现有 DDG 源一致）。
- AI 公司逐家核验：
  - 必须有官网域名，且未被屏蔽。
  - 抓取官网首页成功（HTTP 可达、正文非空）。
  - 公司名与域名/页面标题匹配（去除 LLC / Ltd / GmbH 等后缀后比较核心词）。
  - 任一不满足即丢弃。
- 返回候选统一标记 `_aiVerified = true`；`runPipeline` 增加兜底过滤：AI 来源未核验的候选不得进入结果。
- 日志输出：AI 建议 N 家 / 核验通过 M 家 / 丢弃 K 家 / 实时搜索新增 Q 家。
- 来源说明改为「AI 规划搜索词 + 官网核验」。

### 验收

- 构造“真实域名 + 编造公司”的混合响应，编造项全部被丢弃。
- 官网不可访问、域名与公司名不匹配的候选被丢弃。
- 无官网的 AI 候选不会出现在结果列表。

## 三、竞品库（comps）

### 数据

沿用 `DataStore` 的 `comps` 键，记录结构：

```
{
  id, name, country, website, product, price, moq,
  advantage, threat, leadId, note, createdAt, updatedAt
}
```

`leadId` 可为空（不关联具体客户）。

### 界面

1. 新模块 `modules/comps.html`，导航“客户 360°”分组下新增「⚔️ 竞品库」：
   - 搜索、列表、新增、编辑、删除。
   - 关联客户下拉（来自 leads）。
   - 空状态引导。
2. 客户 360° 新增「⚔️ 竞品」tab：
   - 只显示 `leadId` 等于当前客户的竞品。
   - 支持直接新增 / 删除，新增时自动带入当前 `leadId`。

### 验收

- 新增竞品后刷新仍在；客户 360 对应 tab 可见。
- 编辑、删除生效；删除不影响线索本身。
- 备份/恢复包含 comps（沿用现有 KEYS）。

---

## 风险与回滚

- 移动端 CSS 可能影响桌面：全部规则限定在 `max-width:860px`，桌面断点内不生效。
- 官网核验会增加 AI 源的耗时：最多核验 6 家、并发 2，单页超时 10s；核验失败只影响 AI 源，不影响其他来源。
- 竞品库是新集合，不改旧数据；出问题可隐藏导航项回滚。
