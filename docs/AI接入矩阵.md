# FT Compass · AI × 模块接入矩阵 v1.0

> 核心原则（用户 2026-09-15 定稿）：**关掉 AI，每个模块仍完整可用；开着 AI，每个模块显著变强。**
> AI 是每个板块的默认能力，不是外挂按钮。本矩阵是所有模块的设计前提 + 验收清单。

## 图例
- 🤖 默认：自动触发，无感执行
- 👆 按需：一键触发
- 💾 落点：AI 结果写进哪个字段 / 联动哪个统计卡（必须落库，不许弹完即逝）

## 验收标准（每个模块完成后逐条勾）
1. **可用性**：断网/未配 key，模块核心功能完整可用，AI 按钮给明确引导而非报错
2. **落库**：每条 AI 输出都有持久化字段，刷新不丢、可排序、可导出
3. **联动**：AI 结果至少驱动 1 处统计卡或跨模块动作（如评分→待办）
4. **省时**：AI 路径比手动路径至少省一步（否则是花架子，砍掉）
5. **兜底**：推理模型 max_tokens ≥1024；解析兼容 content/text/reasoning_content；超时/空返回有原始 JSON 提示

## 原版假 AI 换真推理的三个点位
- 原版"AI 评分"= 写死的分数公式 → scoreLead 真推理
- 原版"AI 洞察"= 静态文案 → genReviewInsight 真数据推理
- 原版开发信 = 变量替换模板 → genOutreach 真生成（模板库作为打底兜底）
